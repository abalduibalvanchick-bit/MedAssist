# MedAssist — база знаний интеллектуального медицинского ассистента

Документно-ориентированная база знаний для информационной поддержки клинических решений
и программные средства её обработки. Каждая единица знаний — Markdown-файл с YAML-метаданными;
структура базы описана формально в едином файле схемы и проверяется автоматически.

> Система носит справочный характер, не ставит диагнозы и не назначает лечение.
> Медицинское содержание прошло только модельную верификацию в рамках учебного проекта.

## Состояние

Актуальные цифры всегда в сгенерированных файлах, а не в этом README:

- `indices/statistics.md` — число карточек по доменам и категориям, связи, статусы;
- `indices/validation_report.md` — результат последней проверки валидатором;
- `CHANGELOG.md` — история изменений схемы и базы.

## Структура

```text
kb/
  _schema/schema.yaml     единая схема базы знаний (источник правды)
  diag/                   ПО «Заболевания, симптомы и диагностика»
  pharm/                  ПО «Фармакология и терапия»
  prot/                   ПО «Клинические протоколы и маршрутизация»
  glb/                    глобальная ПО (глоссарий, профили пациентов, дисклеймеры)
  rules/                  продукционные правила (процедурные знания)
  templates/              шаблоны карточек
src/
  schema.py               загрузка схемы и самопроверка
  conditions.py           мини-язык условий: проверка и трёхзначная оценка
  markdown_parser.py      разбор карточки
  repository.py           загрузка базы
  indexer.py              индексы и входящие связи
  linker.py               навигация по связям, материализация обратных связей
  search_engine.py        поиск
  validator.py            проверка структуры, машиночитаемого слоя и правил
  scenarios.py, cli.py    демонстрационные сценарии и консольный интерфейс
scripts/
  migrate_v1_to_v2.py     миграция карточек со схемы v1
  generate_docs.py        документация docs/ из схемы
  generate_indices.py     индексы, каталоги, статистика, дерево проекта
docs/                     описание схемы, связей, условий (генерируется), отчёт о миграции
indices/                  каталоги и статистика (генерируются)
tests/                    автоматические тесты
```

Инвариант идентификации: префикс ID, поле `domain`, папка домена и префикс файла совпадают.
`DIAG-DISEASE-001` → `domain: diag`, `category: disease`, файл `kb/diag/diseases/diag_disease_hypertension.md`.

## Установка и запуск

```bash
pip install -r requirements.txt

python main.py --stats                     # статистика
python main.py --validate                  # проверка базы
python main.py --write-validation-report   # проверка с записью отчёта в indices/
python main.py --search "боль в груди"
python main.py --show DIAG-SYMPTOM-002
python main.py --related DIAG-SYMPTOM-002  # прямые и обратные связи
python main.py --scenario chest_pain
python main.py                             # интерактивное меню

python -m pytest -q                        # тесты
```

После изменения карточек или схемы:

```bash
python scripts/generate_indices.py
python scripts/generate_docs.py
python main.py --write-validation-report
```

## Схема v2 кратко

- **Метаданные**: обязательные поля и перечисления — `docs/metadata_schema.md`.
- **Связи**: только поле `relations` с типом из `docs/link_types.md`; у каждого типа есть обратный,
  который загрузчик выводит автоматически.
- **Машиночитаемый слой**: поля, которые решатель читает напрямую (признаки симптомов, условия
  красных флагов, параметры шкал, таблицы маршрутизации) — `docs/schema.md`.
- **Условия**: единый мини-язык с трёхзначной логикой — `docs/conditions.md`.
- **Правила**: `kb/rules/*.yaml`, формат — `docs/schema.md`, раздел «Правила».
