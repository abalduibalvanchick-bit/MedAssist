# Дифференциальная диагностика — Differential diagnosis

## Определение
Процесс исключения заболеваний со сходной клинической картиной для установления наиболее вероятного диагноза.

## Определение для пациента
Сравнение похожих болезней, чтобы понять, какая из них вероятнее.

## Синонимы и сокращения
дифференциальная диагностика, дифдиагностика, дифференциальный диагноз.

## Контекст использования
Термин используется в карточках: [[DIAG-DIFDIAG-001]], [[DIAG-DIFDIAG-002]], [[DIAG-DIFDIAG-003]]. Синонимы применяются поисковым модулем и распознаванием запросов на естественном языке.
