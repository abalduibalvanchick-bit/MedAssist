# Электрокардиография (ЭКГ) — Electrocardiography

## Определение
Метод регистрации электрической активности сердца; основное исследование при подозрении на ишемию миокарда и нарушения ритма.

## Определение для пациента
Безболезненная запись работы сердца с помощью электродов на коже.

## Синонимы и сокращения
ЭКГ, кардиограмма, электрокардиограмма.
