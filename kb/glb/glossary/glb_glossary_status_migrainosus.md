# Мигренозный статус — Status migrainosus

## Определение
Изнуряющий приступ мигрени продолжительностью более 72 часов.

## Определение для пациента
Приступ мигрени, который длится больше трёх суток.

## Синонимы и сокращения
мигренозный статус, затяжной приступ мигрени.
