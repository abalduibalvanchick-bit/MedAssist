# Острая дыхательная недостаточность (ОДН) — Acute respiratory failure

## Определение
Состояние, при котором система дыхания не обеспечивает нормальный газовый состав крови; клинически проявляется одышкой, цианозом, снижением SpO₂ менее 90 %.

## Определение для пациента
Состояние, при котором организм не получает достаточно кислорода из-за нарушения дыхания.

## Синонимы и сокращения
ОДН, дыхательная недостаточность, гипоксемия.
