# Гиперосмолярное гипергликемическое состояние (ГГС) — Hyperosmolar hyperglycemic state

## Определение
Острая декомпенсация сахарного диабета с выраженной гипергликемией (как правило, более 33,3 ммоль/л), гиперосмолярностью и обезвоживанием без значимого кетоацидоза.

## Определение для пациента
Опасное осложнение диабета с очень высоким сахаром крови и обезвоживанием.

## Синонимы и сокращения
ГГС, гиперосмолярная кома, гиперосмолярное состояние.
