# Пациенты со сниженной функцией почек (СКФ менее 60)

> ⚕️ **Дисклеймер**: Профиль описывает общие ограничения; дозирование определяет врач по инструкции препарата.

## Определение группы
К профилю относятся пациенты с расчётной скоростью клубочковой фильтрации менее 60 мл/мин/1,73 м², что соответствует хронической болезни почек стадии С3 и выше по KDIGO.

## Значение для фармакотерапии
Снижение СКФ меняет выведение препаратов с почечной элиминацией. Для метформина СКФ менее 30 является противопоказанием, при СКФ 30–45 доза ограничивается. На фоне ингибиторов АПФ и блокаторов рецепторов ангиотензина II контролируются калий и креатинин.

## Значение для диагностики
Перед исследованиями с йодсодержащим контрастом у таких пациентов оценивается риск контраст-индуцированной нефропатии, а приём метформина временно приостанавливается (см. карточку взаимодействия).
