# Ингаляционные кортикостероиды (ИГКС)

> **Дисклеймер**: Информация предназначена для медицинских специалистов.

## Общая характеристика
Ингаляционные кортикостероиды (ИГКС) – препараты выбора для базисной (противовоспалительной) терапии бронхиальной астмы. При регулярном применении снижают частоту обострений, улучшают функцию лёгких, контроль симптомов и качество жизни. Являются основой лечения всех пациентов с персистирующей астмой, начиная со ступени 2 (GINA). Не применяются для купирования острых приступов.

## Механизм действия (общий для группы)
Связывание с глюкокортикоидными рецепторами в цитоплазме клеток дыхательных путей → подавление синтеза провоспалительных цитокинов, эозинофилии, активации тучных клеток, макрофагов и лимфоцитов. Снижается гиперреактивность бронхов.

## Представители группы (основные для астмы)
| МНН | Торговые названия | Особенности |
|-----|------------------|-------------|
| Будесонид | Пульмикорт (суспензия для небулайзера), Бенакорт (ДАИ) | Высокая местная эффективность, разрешён у детей с 6 мес |
| Флутиказон пропионат | Фликсотид, Фликсоназе | Наиболее сильный из ИГКС, низкая биодоступность |
| Беклометазон дипропионат | Беклазон, Кленил | Препарат первого выбора для умеренной астмы |
| Циклесонид | Альвеско | Пролекарство, активируется в лёгких, низкая системная биодоступность |

## Общие показания
- Базисная терапия бронхиальной астмы (все ступени 2–5 по GINA) – I класс, уровень A.
- ХОБЛ с частыми обострениями (в комбинации с длительными β2-агонистами).

## Общие противопоказания
- Гиперчувствительность.
- Необоснованное применение для купирования приступов.

## Общие побочные эффекты
- Кандидоз ротоглотки (молочница) – при плохой гигиене (полоскать рот после ингаляции).
- Охриплость голоса, дискомфорт в горле.
- Системные эффекты при длительном применении высоких доз (угнетение функции надпочечников, остеопороз, задержка роста у детей – риск умеренный).

## Клинически значимые взаимодействия
- Одновременное применение ингибиторов CYP3A4 (кетоконазол, ритонавир) может повышать системные уровни некоторых ИГКС (будесонида, флутиказона).

## Особенности выбора
- **Низкие дозы ИГКС** – для ступени 2 GINA (контроль лёгкой астмы).
- **Средние/высокие дозы** – для ступеней 3–4 (при недостаточном контроле).
- У детей предпочтительнее будесонид через небулайзер или спейсер.
- При кандидозе – использование спейсера, полоскание рта после ингаляции.
