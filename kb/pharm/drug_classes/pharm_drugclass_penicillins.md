# Пенициллины (β-лактамные антибиотики, группа пенициллинов)

> **Дисклеймер**: Информация предназначена для медицинских специалистов.

## Общая характеристика
Пенициллины – старейший класс антибиотиков, активный в отношении многих грамположительных и грамотрицательных бактерий. Наиболее широко используется амоксициллин (перорально) и амоксициллин/клавуланат (ингибитор-защищённый). Являются препаратами выбора для амбулаторного лечения внебольничной пневмонии у пациентов без факторов риска и без аллергии.

## Механизм действия (общий для группы)
Ингибируют ферменты транспептидазы (пенициллин-связывающие белки), нарушая синтез пептидогликана клеточной стенки бактерий. Это приводит к осмотическому лизису бактерий (бактерицидное действие). Клавулановая кислота ингибирует β-лактамазы, расширяя спектр.

## Представители группы (важные для респираторных инфекций)
| МНН | Торговые названия | Особенности |
|-----|------------------|-------------|
| Амоксициллин | Флемоксин, Амосин, Оспамокс | Высокая биодоступность, перорально, узкий спектр (Streptococcus pneumoniae, Haemophilus influenzae) |
| Амоксициллин/клавуланат | Аугментин, Амоксиклав, Флемоклав | Добавление клавулановой кислоты – защита от β-лактамаз, активен против Staphylococcus aureus, анаэробов |
| Пенициллин G (бензилпенициллин) | Бензилпенициллин | в/м или в/в, используется внутрибольнично, но не для эмпирической терапии пневмонии (только при чувствительных пневмококках) |

## Сравнительная характеристика (для пневмонии)
| Параметр | Амоксициллин | Амоксициллин/клавуланат |
|----------|--------------|--------------------------|
| Спектр | пневмококк, H. influenzae (штаммы без продукции β-лактамаз) | расширен (стафилококки, анаэробы, бета-лактамазопродуцирующие) |
| Грам-отрицательные | умеренный | умеренный |
| Дозы при пневмонии | 500 мг 3 раза/сут или 1000 мг 2 раза/сут | 875/125 мг 2 раза/сут |
| ЖКТ-побочные эффекты | низкие | умеренные |
| Резистентность пневмококка | может быть высокой (но в РФ низкая) | сохраняется активность |

## Общие показания
- Внебольничная пневмония (амбулаторно, легкая без факторов риска)
- Острый бронхит, обострение ХОБЛ
- Синусит, средний отит
- Инфекции мочевыводящих путей (амоксициллин/клавуланат)

## Общие противопоказания
- Гиперчувствительность к пенициллинам (аллергия – крапивница, анафилаксия), перекрёстная аллергия с цефалоспоринами (5–10%).
- Хроническая почечная недостаточность (коррекция доз при СКФ < 30).

## Общие побочные эффекты
- Аллергические реакции (сыпь, крапивница, анафилаксия – редко).
- Диарея, тошнота (особенно для амоксициллин/клавуланата).
- Псевдомембранозный колит (редко).

## Клинически значимые взаимодействия
- Аллопуринол → повышение риска кожной сыпи.
- Пероральные контрацептивы (теоретически снижение эффективности, незначительно).
- Варфарин — возможно усиление антикоагулянтного эффекта, требуется контроль МНО.

## Особенности выбора
- Амоксициллин – препарат выбора для амбулаторной пневмонии у пациентов без сопутствующих заболеваний и без недавнего приёма антибиотиков.
- Амоксициллин/клавуланат – при недавнем приёме антибиотиков, наличии бронхоэктазов, ХОБЛ.
- При аллергии на пенициллины (анафилаксия) – цефалоспорины противопоказаны, использовать фторхинолоны (левофлоксацин) или макролиды (азитромицин) в монорежиме (только при лёгкой атипичной пневмонии).
