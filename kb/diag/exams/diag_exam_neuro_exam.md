# Неврологический осмотр

> ⚕️ **Дисклеймер**: Информация носит справочный характер и предназначена для медицинских специалистов.

## Определение
Неврологический осмотр – комплексный метод оценки функций нервной системы, включающий исследование черепных нервов, двигательной, чувствительной, координаторной сфер, рефлексов и высших психических функций. При мигрени осмотр обычно не выявляет очаговой патологии, но необходим для исключения вторичных причин головной боли (опухоль, аневризма, инсульт и др.).

## Назначение метода
- Дифференциальная диагностика головной боли (мигрень vs. другие органические поражения).
- Исключение «красных флагов» (неврологический дефицит, менингеальные знаки).
- Оценка тяжести и сопутствующих неврологических расстройств.

## Показания
- Впервые возникшая или изменившая свой характер головная боль.
- Подозрение на мигрень (для исключения органической патологии).
- Наличие «красных флагов» (внезапная сильнейшая головная боль, неврологический дефицит, симптомы менингита, изменения сознания).

## Диагностическая роль
При типичной мигрени неврологический осмотр обычно **не выявляет** очаговых нарушений. Однако он обязателен для исключения:
- внутричерепных образований (опухоль, абсцесс);
- сосудистых катастроф (геморрагия, тромбоз);
- инфекций (менингит, энцефалит);
- заболеваний черепных нервов (невралгии, невриты).

## Интерпретация результатов
| Находка | Возможное значение |
|---------|-------------------|
| Отклонений нет (нормальный неврологический статус) | Поддерживает диагноз первичной головной боли (мигрень, головная боль напряжения) |
| Очаговая неврологическая симптоматика (асимметрия, слабость, дефицит полей зрения) | Исключить инсульт, опухоль, рассеянный склероз – требуется нейровизуализация |
| Менингеальные знаки | Исключить менингит, субарахноидальное кровоизлияние |
| Патология черепных нервов (например, невралгия тройничного нерва) | Рассмотреть другие причины боли |

## Ограничения
- Не заменяет нейровизуализацию (КТ, МРТ) при наличии «красных флагов».
- У пациентов с мигренозной аурой могут быть преходящие очаговые симптомы (но они обратимы).

## Последовательность назначения
- **Первичный приём при жалобах на головную боль**: всегда включать неврологический осмотр.
- **Перед установлением диагноза мигрени**: для исключения органической патологии.

## Особенности у отдельных групп
- **Дети**: осмотр может быть затруднён, но обязателен для исключения объёмных образований.
- **Пожилые**: более высокая вероятность вторичных причин (височный артериит, сосудистая патология).
