# Гликированный гемоглобин (HbA1c)

> ⚕️ **Дисклеймер**: Информация носит справочный характер и предназначена для медицинских специалистов.

## Определение
Гликированный гемоглобин (HbA1c) отражает среднюю концентрацию глюкозы в крови за предшествующие 2–3 месяца. Образуется в результате неферментативного присоединения глюкозы к гемоглобину эритроцитов. Выражается в процентах (%) или ммоль/моль (IFCC единицы).

## Назначение метода
Диагностика сахарного диабета, оценка степени компенсации углеводного обмена, прогнозирование риска осложнений.

## Показания
- Скрининг сахарного диабета (особенно у пациентов, которым трудно соблюдать голодание).
- Диагностика диабета (при отсутствии классических симптомов – подтверждение повторным тестом).
- Мониторинг эффективности лечения СД2 (каждые 3 месяца у пациентов, не достигших цели; каждые 6 месяцев у стабильных).
- Оценка риска осложнений (каждое снижение HbA1c на 1% снижает риск микроангиопатий на 35–40%).

## Диагностическая роль
HbA1c является «золотым стандартом» для долгосрочного контроля гликемии. Для диагностики СД2 пороговое значение ≥ 6.5% (48 ммоль/моль) при стандартизированном методе (NGSP/IFCC). Не требует голодания, стабилен, не зависит от случайных колебаний гликемии.

## Интерпретация результатов

| HbA1c (% (ммоль/моль)) | Интерпретация |
|------------------------|----------------|
| < 5.7% (< 39 ммоль/моль) | Норма |
| 5.7–6.4% (39–47 ммоль/моль) | Преддиабет (высокий риск диабета) |
| ≥ 6.5% (≥ 48 ммоль/моль) | Сахарный диабет (требует подтверждения) |

**Целевые значения для пациентов с диабетом:**
- Для большинства взрослых: **< 7.0%** (< 53 ммоль/моль)
- При строгом контроле (молодые, без осложнений): < 6.5% (48 ммоль/моль)
- Для пожилых, с тяжёлыми осложнениями или ограниченной продолжительностью жизни: < 7.5–8.0% (58–64 ммоль/моль)

## Ограничения
- Ложнозаниженные результаты: гемолиз, анемия (недавнее переливание крови), беременность, хроническая почечная недостаточность (уремия), приём высоких доз витамина С и E.
- Ложнозавышенные результаты: железодефицитная анемия, гипербилирубинемия, хронический алкоголизм, уремия.
- Не применим для диагностики диабета у пациентов с вариантами гемоглобина (гемоглобинопатии) – требуется измерение глюкозы.

## Последовательность назначения
- **Скрининг**: может использоваться как альтернатива глюкозе натощак, но с учётом ограничений.
- **Диагностика**: при значении ≥ 6.5% без симптомов – повторить (лучше другой метод, например глюкоза натощак).
- **Мониторинг**: каждые 3–6 месяцев для контроля эффективности лечения.

## Особенности у отдельных групп
- **Беременные**: HbA1c менее точен для диагностики гестационного диабета (предпочтительнее ПГТТ); физиологически снижен во II триместре.
- **Дети**: критерии те же, но следует исключать HbA1c-варианты.
- **Пожилые**: цель лечения индивидуализируют, более высокие пороги допустимы.
