# Чек-лист врача: первичный приём при сахарном диабете 2 типа

> Документ предназначен для стандартизации действий врача на первичном приёме.

## Жалобы и анамнез
- [ ] полиурия, полидипсия
- [ ] немотивированная потеря веса
- [ ] общая слабость, утомляемость
- [ ] рецидивирующие инфекции (мочевыводящие пути, кожа)
- [ ] факторы риска: ожирение, наследственность, гиподинамия, возраст ≥ 45 лет

## Объективное обследование
- [ ] [[DIAG-EXAM-005]] глюкоза крови (капиллярная или венозная) – экспресс-тест
- [ ] [[DIAG-EXAM-006]] HbA1c (если доступен)
- [ ] артериальное давление, частота сердечных сокращений
- [ ] масса тела, рост, расчёт ИМТ
- [ ] осмотр стоп (вибрационная чувствительность, пульсация, деформации)
- [ ] оценка зрения (ориентировочно)

## Оценка риска
- [ ] [[PROT-SCALE-002]] – расчёт баллов по шкале риска осложнений
- [ ] наличие сердечно-сосудистых заболеваний (ИБС, инсульт, ХСН)
- [ ] наличие ХБП (СКФ, альбуминурия)
- [ ] курение, дислипидемия

## Диагностические решения
- [ ] подтверждён диагноз [[DIAG-DISEASE-006]] (по критериям глюкоза натощак ≥ 7.0 или HbA1c ≥ 6.5%)
- [ ] необходимость дополнительных обследований (липидный профиль, креатинин, СКФ, ОАМ)
- [ ] исключение острых осложнений (кетоз, ГГС)

## Тактика ведения
- [ ] назначить обучение в школе диабета (обязательно)
- [ ] определить план лечения [[PROT-PROTOCOL-002]]
- [ ] стартовая терапия: метформин (при отсутствии противопоказаний) – доза в соответствии с [[PHARM-REGIMEN-002]]
- [ ] определить маршрут пациента (амбулаторно / срочная консультация эндокринолога / госпитализация) по [[PROT-ROUTING-002]]
- [ ] при наличии высокого сердечно-сосудистого риска – рассмотреть добавление ингибитора SGLT2 или агониста ГПП-1

## Информирование пациента
- [ ] объяснить суть заболевания и его хроническое течение
- [ ] выдать памятку [[PROT-PATIENT_INFO-002]]
- [ ] обучить правилам самоконтроля глюкозы (если есть глюкометр)
- [ ] объяснить признаки гипогликемии и гипергликемии, когда срочно обратиться

## Завершение приёма
- [ ] назначить контрольный визит (через 2–4 недели)
- [ ] записать план лечения в электронную карту
- [ ] при необходимости выдать направления на анализы, консультации (окулист, невролог)
