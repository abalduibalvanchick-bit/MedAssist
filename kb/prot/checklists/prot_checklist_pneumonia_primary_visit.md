# Чек-лист врача: первичный приём при внебольничной пневмонии

> Документ предназначен для стандартизации действий врача на первичном приёме.

## Жалобы и анамнез
- [ ] кашель (сухой, продуктивный, характер мокроты)
- [ ] лихорадка (длительность, максимальная температура)
- [ ] одышка (частота дыхания, связь с нагрузкой)
- [ ] боль в груди (при дыхании, кашле)
- [ ] слабость, потливость
- [ ] факторы риска: возраст ≥ 65, курение, ХОБЛ, диабет, алкоголизм, иммуносупрессия

## Объективное обследование
- [ ] [[DIAG-EXAM-001]] артериальное давление, частота пульса
- [ ] [[DIAG-EXAM-004]] SpO₂ (пульсоксиметрия) – оценка гипоксемии
- [ ] частота дыхания (ЧДД)
- [ ] температура тела
- [ ] аускультация лёгких (хрипы, ослабление дыхания, крепитация)
- [ ] оценка сознания (спутанность – критерий CURB-65)

## Оценка тяжести
- [ ] [[PROT-SCALE-004]] – шкала CURB-65 (C, U, R, B, 65) – сумма баллов

## Инструментальная / лабораторная диагностика
- [ ] [[DIAG-EXAM-004]] рентгенография грудной клетки (обязательна для подтверждения)
- [ ] [[DIAG-EXAM-003]] общий анализ крови, СРБ, прокальцитонин (по показаниям)
- [ ] газовый состав (при SpO₂ < 92% или тяжёлом состоянии)
- [ ] глюкоза, креатинин, мочевина, электролиты
- [ ] микробиологическое исследование мокроты, гемокультуры (при стационаре)

## Диагностические решения
- [ ] клинически подтверждён диагноз [[DIAG-DISEASE-003]]
- [ ] рентгенологически подтверждён
- [ ] дифференциальная диагностика (с сердечной недостаточностью, ТЭЛА, опухолью)

## Тактика ведения
- [ ] выбор места лечения (амбулаторно / стационар / ОРИТ) по [[PROT-ROUTING-004]]
- [ ] назначить антибиотикотерапию согласно [[PHARM-REGIMEN-004]] (с учётом тяжести, коморбидности, аллергии)
- [ ] определить необходимость госпитализации (при CURB-65 ≥ 2, тяжёлой гипоксемии, социальных факторах)
- [ ] назначить вспомогательную терапию (жаропонижающие, оксигенотерапия, гидратация)
- [ ] запланировать контроль через 48–72 часа (при амбулаторном лечении)

## Информирование пациента
- [ ] объяснить важность полного курса антибиотиков
- [ ] выдать памятку [[PROT-PATIENT_INFO-004]]
- [ ] обучить признакам ухудшения (одышка, цианоз, спутанность) и необходимости срочного обращения
- [ ] рекомендовать обильное питьё, постельный режим

## Завершение приёма
- [ ] выдать рецепты (антибиотики, при необходимости противокашлевые, жаропонижающие)
- [ ] назначить контрольный визит (через 2–3 дня для амбулаторных; для госпитализированных – направить в стационар)
- [ ] записать диагноз и план лечения в медицинскую документацию
