# Чек-лист врача: первичный приём при мигрени

> Документ предназначен для стандартизации действий врача на первичном приёме.

## Жалобы и анамнез
- [ ] характер головной боли (пульсирующая, сдавливающая)
- [ ] локализация (часто односторонняя)
- [ ] интенсивность (ВБШ от 0 до 10)
- [ ] наличие ауры (зрительные, сенсорные, речевые нарушения перед болью)
- [ ] сопутствующие симптомы (тошнота, рвота, светобоязнь, звукобоязнь)
- [ ] частота приступов (дней с мигренью в месяц)
- [ ] триггеры (продукты, сон, стресс, гормональные факторы)
- [ ] принимаемые препараты для купирования, частота использования
- [ ] влияние на трудоспособность (MIDAS)

## Объективное обследование
- [ ] [[DIAG-EXAM-001]] артериальное давление, пульс
- [ ] неврологический осмотр (черепные нервы, двигательная, чувствительная сфера, рефлексы)
- [ ] оценка менингеальных знаков (при подозрении на инфекцию)

## Инструментальная диагностика (при наличии "красных флагов")
- [ ] КТ / МРТ головного мозга (при внезапной сильнейшей боли, неврологическом дефиците)
- [ ] ЭЭГ (не рутинно)

## Оценка тяжести
- [ ] [[PROT-SCALE-006]] MIDAS – сумма баллов за 3 месяца
- [ ] количество мигренозных дней/месяц (≥4 – показание к профилактике)

## Диагностические решения
- [ ] подтверждён диагноз [[DIAG-DISEASE-005]] (по критериям ICHD-3)
- [ ] исключены вторичные причины ( неврологический дефицит, красные флаги)

## Тактика ведения
- [ ] назначить купирующую терапию (НПВС / триптаны) согласно [[PHARM-REGIMEN-006]]
- [ ] при MIDAS ≥11 или ≥4 дней мигрени/месяц – назначить профилактическую терапию (β-блокатор, топирамат, амитриптилин)
- [ ] дать рекомендации по изменению образа жизни (дневник, избегание триггеров, режим сна)
- [ ] определить маршрут по [[PROT-ROUTING-006]] (амбулаторно / невролог / экстренно)

## Информирование пациента
- [ ] объяснить, что мигрень – хроническое заболевание, но поддающееся контролю
- [ ] выдать памятку [[PROT-PATIENT_INFO-006]]
- [ ] обучить приёму препаратов (не злоупотреблять анальгетиками, принимать триптаны в начале приступа)
- [ ] указать признаки, когда надо срочно обращаться (изменение характера боли, неврологический дефицит)

## Завершение приёма
- [ ] назначить контрольный визит через 1–3 месяца (оценка эффективности профилактики)
- [ ] выдать рецепты (триптаны, при необходимости профилактические препараты)
- [ ] рекомендовать ведение дневника головной боли
