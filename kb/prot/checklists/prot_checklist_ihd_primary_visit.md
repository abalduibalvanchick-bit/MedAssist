# Чек-лист врача: первичный приём при ишемической болезни сердца (стабильная стенокардия)

> Документ предназначен для стандартизации действий врача на первичном приёме.

## Жалобы и анамнез
- [ ] боли/дискомфорт в груди (характер, локализация, иррадиация)
- [ ] связь с физической нагрузкой, эмоциональным стрессом
- [ ] длительность приступа, что купирует (нитроглицерин, отдых)
- [ ] одышка, сердцебиение, перебои, слабость, головокружение
- [ ] факторы риска: курение, АГ, дислипидемия, СД, ожирение, семейный анамнез

## Объективное обследование
- [ ] [[DIAG-EXAM-001]] измерение артериального давления
- [ ] частота сердечных сокращений
- [ ] оценка пульса (ритмичность, частота)
- [ ] аускультация сердца (тоны, шумы)
- [ ] признаки сердечной недостаточности (отёки, хрипы в лёгких, набухание шейных вен)

## Инструментальная диагностика (обязательная первичная)
- [ ] [[DIAG-EXAM-002]] ЭКГ в покое (12 отведений)
- [ ] Эхокардиография (оценка ФВ, локальной сократимости, клапанов) – по возможности

## Оценка функционального класса и риска
- [ ] [[PROT-SCALE-003]] – определение CCS класса стенокардии
- [ ] [[PROT-SCALE-003]] – оценка риска (баллы)

## Диагностические решения
- [ ] подтверждён диагноз [[DIAG-DISEASE-002]] (на основании типичной стенокардии или данных инструментальных методов)
- [ ] необходимость нагрузочных тестов (тредмил, ВЭМ, стресс-ЭхоКГ, КТ-коронарография) – при неясном диагнозе или стратификации риска
- [ ] необходимость лабораторных исследований (липидный профиль, глюкоза, HbA1c, креатинин)

## Тактика ведения
- [ ] назначить антиангинальную терапию (β-блокаторы / БКК, при необходимости нитраты)
- [ ] назначить вторичную профилактику: антитромбоцитарные (аспирин), статины (интенсивные)
- [ ] назначить [[PHARM-NONPHARM-003]] (немедикаментозное лечение: диета, физнагрузка, отказ от курения)
- [ ] определить маршрут пациента по [[PROT-ROUTING-003]] (амбулаторно / направление к кардиологу / на коронарографию)
- [ ] при высоком риске или рефрактерной стенокардии – направить на коронарографию

## Информирование пациента
- [ ] объяснить суть заболевания и важность приёма препаратов (избегать самовольной отмены)
- [ ] выдать памятку [[PROT-PATIENT_INFO-003]]
- [ ] обучить действиям при приступе стенокардии (принять нитроглицерин, вызвать скорую при отсутствии эффекта через 5 мин)
- [ ] объяснить признаки ухудшения (нестабильная стенокардия) и необходимость срочного обращения

## Завершение приёма
- [ ] назначить контрольный визит (через 2–4 недели для оценки переносимости терапии)
- [ ] выдать рецепты, направления на анализы
- [ ] записать план лечения в медицинскую документацию

- [Терапия назначена]
- [Маршрут определён]
