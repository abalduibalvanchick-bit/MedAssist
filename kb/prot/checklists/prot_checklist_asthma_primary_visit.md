# Чек-лист врача: первичный приём при бронхиальной астме

> Документ предназначен для стандартизации действий врача на первичном приёме.

## Жалобы и анамнез
- [ ] одышка, свистящее дыхание, кашель (продолжительность, частота)
- [ ] связь симптомов с триггерами (аллергены, холод, физическая нагрузка)
- [ ] ночные пробуждения
- [ ] частота использования ингалятора облегчения (SABA) за последнюю неделю
- [ ] анамнез аллергических заболеваний (ринит, экзема, пищевая аллергия)
- [ ] курение, пассивное курение, домашние животные, условия труда
- [ ] приступы, потребовавшие госпитализации или вызова скорой

## Объективное обследование
- [ ] [[DIAG-EXAM-001]] артериальное давление, пульс
- [ ] частота дыхания, сатурация (SpO₂)
- [ ] аускультация лёгких (свистящие хрипы на выдохе)
- [ ] оценка использования вспомогательной мускулатуры
- [ ] осмотр верхних дыхательных путей (ринит)

## Инструментальная диагностика
- [ ] [[DIAG-EXAM-008]] спирометрия с бронходилатационным тестом (прирост ОФВ1 ≥12% и ≥200 мл – подтверждение астмы)
- [ ] пикфлоуметрия (при наличии)
- [ ] при нормальной спирометрии и клиническом подозрении – бронхопровокационный тест (метахолин) или аллергодиагностика

## Оценка контроля
- [ ] [[PROT-SCALE-005]] – тест контроля астмы (ACT) – сумма баллов (5–25)
- [ ] оценка частоты использования SABA (>2 раз/нед – признак неконтролируемой астмы)

## Диагностические решения
- [ ] подтверждён диагноз [[DIAG-DISEASE-004]]
- [ ] тяжесть (интермиттирующая, персистирующая лёгкая, средняя, тяжёлая) по клиническим критериям
- [ ] фенотип (аллергический, неаллергический, аспириновая астма и др.)
- [ ] исключение других причин обструкции (ХОБЛ, сердечная недостаточность, трахеобронхиальная дискинезия)

## Тактика ведения
- [ ] назначить базисную терапию: ИГКС (низкие дозы) – все пациенты с персистирующей астмой (ступень 2 и выше)
- [ ] при недостаточном контроле – повышение дозы ИГКС или добавление LABA (ступень 3)
- [ ] назначить препарат облегчения: SABA короткого действия (сальбутамол)
- [ ] обучить технике ингаляции (с использованием спейсера)
- [ ] составить письменный план действий (самоконтроль, увеличение дозы при ухудшении, вызов скорой)
- [ ] определить маршрут по [[PROT-ROUTING-005]] (амбулаторно / пульмонолог / аллерголог / госпитализация)
- [ ] при тяжёлом обострении (ПСВ < 50%, невозможность говорить) – экстренная госпитализация по [[PROT-EMERGENCY_P-005]]

## Информирование пациента
- [ ] объяснить необходимость регулярной терапии (базисные препараты даже при отсутствии симптомов)
- [ ] выдать памятку [[PROT-PATIENT_INFO-005]]
- [ ] обучить пользоваться ингалятором, спейсером, пикфлоуметром (если назначен)
- [ ] объяснить признаки ухудшения и действия при них (план действий)

## Завершение приёма
- [ ] назначить контрольный визит (через 4–6 недель для оценки контроля и коррекции терапии)
- [ ] выдать рецепты (ИГКС, SABA, при необходимости спейсер)
- [ ] рекомендовать вакцинацию против гриппа (ежегодно) и пневмококка
- [ ] направить к аллергологу (при подозрении на аллергический фенотип)
