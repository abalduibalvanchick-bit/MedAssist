# Наблюдение пациента: Ишемическая болезнь сердца (хроническая)

> Документ описывает порядок контроля и ведения пациента после начального этапа лечения.

## Цель наблюдения
- контроль эффективности антиангинальной и профилактической терапии
- раннее выявление ухудшения (нестабильная стенокардия, сердечная недостаточность, аритмии)
- мониторинг безопасности (геморрагии, мышечные симптомы)
- коррекция терапии и вторичная профилактика

## Кого наблюдаем
- пациенты с подтверждённой [[DIAG-DISEASE-002]] хронической ИБС
- пациенты после инфаркта миокарда, стентирования, АКШ
- пациенты с высоким риском, получающие антитромбоцитарную и липидснижающую терапию

## Частота наблюдения
- **Стабильное течение, ФК I–II, низкий риск**: каждые 6–12 месяцев
- **ФК II–III или умеренный риск**: каждые 3–6 месяцев
- **После перенесённого ОКС/стентирования/АКШ**: контроль через 2–4 недели, затем 3–6 месяцев
- **При ухудшении симптомов**: внеплановый визит (немедленно)

## Контрольные параметры
| Параметр | Частота | Цель |
|----------|---------|------|
| Жалобы, ФК стенокардии | каждый визит | оценка эффективности |
| Артериальное давление | каждый визит | контроль АД < 130/80 |
| ЧСС | каждый визит | на β-блокаторах 50–60 уд/мин |
| ЭКГ в покое | при плановом визите (каждые 6–12 мес) или по показаниям | выявление ишемии, аритмий |
| Липидный профиль (ЛПНП) | через 4–8 недель после коррекции статинов, затем 1 раз в 6 мес | ЛПНП < 1.4 ммоль/л ( < 1.0 при очень высоком риске) |
| Креатинин, СКФ, калий | 1 раз в 6–12 мес | оценка почечной функции (особенно при ХБП, приёме диуретиков/иАПФ) |
| КФК (при мышечных симптомах) | по показаниям | исключение миопатии |
| Полный анализ крови, коагулограмма | 1 раз в 6–12 мес (при приёме антитромбоцитарных) | оценка риска кровотечений |

## Методы контроля
- Клинический осмотр, оценка ФК стенокардии (PROT-SCALE-003)
- Лабораторные исследования (липиды, креатинин, глюкоза)
- Инструментальные: ЭКГ (плановая или по показаниям), ЭхоКГ (каждые 1–2 года), нагрузочные тесты (при подозрении на ухудшение)

## Критерии эффективности лечения
- Отсутствие стенокардии или редукция ФК (например, с III до II)
- Достижение целевого ЛПНП < 1.4 ммоль/л
- Стабильное АД < 130/80
- Отсутствие побочных эффектов (геморрагии, миалгии)

## Критерии ухудшения и действия
| Ухудшение | Действие |
|-----------|----------|
| Новое появление/учащение приступов стенокардии (переход на более высокий ФК) | Пересмотреть антиангинальную терапию (добавить второй препарат / нитраты). При нестабильности → [[PROT-EMERGENCY_P-003]] |
| ЛПНП выше цели | Увеличить дозу статина или добавить эзетимиб |
| Мышечные симптомы (миалгии) + повышение КФК | Пересмотреть статин (снизить дозу, заменить на другой, добавить эзетимиб) |
| ЖКТ-кровотечение, гематурия | Оценить необходимость антитромбоцитарной терапии (снижение дозы или отмена) |
| Сердечная недостаточность (одышка, отёки) | Назначить диуретики, иАПФ/БРА, β-блокаторы (по показаниям), направить по маршруту для ХСН |

## Коррекция терапии
- В соответствии с [[PHARM-REGIMEN-003]]
- При рефрактерной стенокардии (III–IV ФК) – направить на коронарографию для реваскуляризации
- При непереносимости статинов – эзетимиб, ингибиторы PCSK9
- При высоком риске кровотечений – рассмотреть монотерапию аспирином (без клопидогрела)

## Переход на другой уровень наблюдения
- Амбулаторное наблюдение → срочная консультация кардиолога (при прогрессировании симптомов)
- Амбулаторное наблюдение → госпитализация (нестабильная стенокардия, ОКС, тяжёлая сердечная недостаточность)
- Плановое наблюдение → экстренная помощь (по PROT-EMERGENCY_P-003)
