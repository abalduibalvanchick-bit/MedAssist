# Наблюдение пациента: Сахарный диабет 2 типа

> Документ описывает порядок контроля и ведения пациента после начального этапа лечения.

## Цель наблюдения
- контроль гликемического профиля (HbA1c, глюкоза натощак)
- раннее выявление осложнений и коррекция терапии
- снижение сердечно-сосудистого риска
- повышение приверженности лечению

## Кого наблюдаем
- пациенты с диагнозом [[DIAG-DISEASE-006]] Сахарный диабет 2 типа
- пациенты, получающие немедикаментозную и/или медикаментозную терапию
- пациенты после эпизодов острой декомпенсации

## Частота наблюдения
- **первичный контроль**: через 4 недели после начала терапии (оценка переносимости метформина/других препаратов, гликемия)
- **повторный контроль (не достигнута цель)**: каждые 3 месяца
- **достигнута цель (стабильный контроль)**: каждые 3–6 месяцев
- **при изменении терапии (добавление/замена препарата)**: через 4–8 недель; затем 3–6 месяцев
- **при наличии осложнений или высоком риске**: чаще, по индивидуальному плану (например, ежемесячно для пациентов на инсулине)

## Контрольные параметры

| Параметр | Частота | Цель |
|----------|---------|------|
| HbA1c | каждые 3 месяца (при изменении терапии); 6 месяцев при стабильной компенсации | < 7.0% (индивидуально: 7.5–8.0% для пожилых/хрупких) |
| Глюкоза натощак | при каждом визите (если есть глюкометр – домашний дневник) | 4.4–7.0 ммоль/л |
| Артериальное давление | каждый визит | < 130/80 |
| Липидный профиль (ЛПНП, триглицериды, ЛПВП) | ежегодно | ЛПНП < 1.8 (при очень высоком риске < 1.4) |
| Креатинин, СКФ | 2 раза в год | стабильность |
| Альбуминурия | 1 раз в год (при нормальной – повтор через 2 года, при протеинурии – чаще) | < 30 мг/г |
| Осмотр окулиста | 1 раз в год (если нет ретинопатии, при наличии – чаще) | отсутствие/регресс патологии |
| Осмотр ног (неврологический, сосудистый) | каждый визит | целостность, чувствительность |
| Масса тела, ИМТ | каждый визит | снижение при ожирении |

## Методы контроля
- [[DIAG-EXAM-006]] Гликированный гемоглобин (HbA1c)
- [[DIAG-EXAM-005]] Глюкоза натощак (лабораторная или глюкометр)
- [[DIAG-EXAM-001]] Измерение АД
- Лабораторные исследования (креатинин, СКФ, альбуминурия, липиды)

## Критерии эффективности лечения
- Достижение целевого HbA1c (< 7% для большинства взрослых)
- Отсутствие прогрессирования ретинопатии, нефропатии, нейропатии
- Стабильное АД < 130/80
- Хорошая переносимость терапии, отсутствие гипогликемий

## Критерии ухудшения и действия
| Ухудшение | Действие |
|-----------|----------|
| Повышение HbA1c > 7.5–8% на фоне терапии (при исходно хорошем контроле) | Рассмотреть добавление второго/третьего препарата (по [[PHARM-REGIMEN-002]]) |
| Появление микроальбуминурии или снижение СКФ на 30% за 1 год | Направить к нефрологу, рассмотреть ингибиторы SGLT2, контроль АД |
| Возникновение непролиферативной ретинопатии | Направить к окулисту для лазерной коагуляции, ужесточить контроль гликемии |
| Развитие диабетической стопы (язва) | Экстренная госпитализация, направление к хирургу/подологу |
| Тяжёлая гипергликемия (> 25–30 ммоль/л) с симптомами | Направить по экстренному маршруту (скорая помощь), [[PROT-EMERGENCY_P-002]] |
| Частые гипогликемии | Снизить дозу сульфонилмочевины/инсулина, обучить пациента |

## Коррекция терапии
- В соответствии с [[PHARM-REGIMEN-002]]
- Переход на более интенсивные режимы (двойная комбинация, тройная комбинация, инсулин)
- При высоком сердечно-сосудистом риске – добавить ингибитор SGLT2 или агонист ГПП-1 при отсутствии противопоказаний

## Переход на другой уровень наблюдения
- Амбулаторное плановое наблюдение → срочное направление к эндокринологу (при рефрактерности)
- Амбулаторное наблюдение → госпитализация (декомпенсация, осложнения)
- Плановое наблюдение → экстренная помощь при ГГС/ДКА
